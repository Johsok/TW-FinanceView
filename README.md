# TW-FinanceView — 台股財報小助手（GitHub Pages）

對應美股 [US-FinanceView](https://github.com/Johsok/US-FinanceView)。

- 網站：https://johsok.github.io/TW-FinanceView/
- JSON：https://johsok.github.io/TW-FinanceView/earnings_data.json
- 爬蟲：[TW-Finance](https://github.com/Johsok/TW-Finance) 每日寫入 `earnings_data.json`、`holidays.json`、`DailyLog.txt`

本倉庫以 GitHub Actions 自 `Johsok/TW-Finance` 的 `main` 同步上述三個檔案（TW-Finance 為公開倉庫，不需額外 PAT）。
